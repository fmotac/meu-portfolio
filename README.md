# Meu Portfólio

Projeto de exemplo do e-book **VS Code Turbinado com IA** (Kit do Dev na Era da IA, Vol. 1) — Prof. Flávio Mota.

## Como abrir
1. Abra esta pasta no VS Code (`File > Open Folder`).
2. Instale a extensão **Live Server**.
3. Clique com o botão direito em `index.html` > **Open with Live Server**.

## Estrutura
- `index.html` — estrutura da página
- `style.css` — estilos e tema claro/escuro
- `app.js` — projetos, troca de tema e formulário
